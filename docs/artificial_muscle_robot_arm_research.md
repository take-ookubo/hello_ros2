# 高分子・編組メッシュ・人工筋肉を使うロボットアームの調査

調査日：2026-11-07。日本国内での研究開発を想定。

関連資料：[半導体・製造装置からの完全内製](robot_arm_full_stack_research_and_requirements.md)、[収穫・水利栓用ハードウェア比較](harvesting_robot_hardware_comparison.md)。本資料は人工筋肉方式への変更による研究・構成・費用の差を扱う。市販材料・電子部品を使う試作と、材料合成・半導体までの完全内製は区別する。

## 1. 結論

**高分子チューブと編組メッシュで筋肉のように引っ張るアームは実現例があり、最初の比較対象にはMcKibben型の空圧人工筋肉が適する。** 初号機では、骨格・関節・腱・角度/張力センサを備えた筋骨格型アームにする案を推奨する。これは公開研究・製品資料に基づく設計上の判断で、今回の用途で実機比較した結果ではない。

研究上の発展候補は、液圧McKibben型、HASEL、誘電エラストマー、電気流体繊維、3Dプリント流体アクチュエータ。果実への柔らかな接触と、水利栓の固着を解く高トルクでは、適する方式が異なる。

人工筋肉方式は、関節に置くモータ・減速機を減らせる一方、圧力源、弁、高電圧駆動、温度管理、状態推定などが増える。**「柔らかい材料だから、アーム全体も安く簡単になる」とは限らない。**

## 2. 「高分子ポリカーボネートメッシュ」の解釈

今回確認した一次資料では、この語そのものを確立した駆動方式名としては特定できなかった。次の材料・構造を分けて扱う。

| 言葉・候補 | 主な役割 | 人工筋肉との関係 |
|---|---|---|
| ポリカーボネート（PC） | 骨格、カバー、構造材など | 一般的なPC部材をメッシュにするだけで、電力を収縮力へ変換する機構が成立するわけではない |
| 高分子エラストマー | 変形するチューブ、膜、弾性体 | シリコーン、ゴム、ポリウレタン系等。方式に合う弾性・耐久性が必要 |
| 編組メッシュ・繊維スリーブ | 膨張方向を拘束し、軸方向の収縮へ変換 | McKibben型に近い。メッシュの幾何が駆動特性を決める |
| 炭素繊維・CFRP | 補強、軽量骨格、用途によって導電部 | 通常の構造用炭素繊維と、能動的な人工筋肉材料を区別 |
| カーボンナノチューブ（CNT） | 電極、発熱体、複合繊維、特殊な撚糸アクチュエータ | 普通の炭素繊維やPCとは異なる材料・製造技術 |
| ポリマーの編物・織物 | 異方的な伸縮・拘束、筋肉の束化 | 材料と構造に加え、空圧・電界・熱等のエネルギー源が必要 |

PCを骨格として使い、別の人工筋肉で荷重を支える実験例もある。したがって、材料名が同じでも「骨」と「筋肉」を取り違えない。[PC梁と人工筋肉の研究例](https://pmc.ncbi.nlm.nih.gov/articles/PMC11048576/)

ユーザーの表現に最も近いと考えられるのは、**柔らかい内管＋繊維メッシュ＋圧力源**の組合せ。ただし特定の論文・製品を指すと断定はしない。

## 3. 駆動方式の比較

以下の適性・採否は本資料の設計評価。性能は材料、寸法、駆動条件、束化方法によって変わり、方式名だけで決まらない。

| 方式 | 原理・材料 | 利点 | アーム化での課題 | 初号機での位置づけ |
|---|---|---|---|---|
| 空圧McKibben型 | 弾性チューブ＋編組繊維。加圧で径が増え長さが縮む | 製品・研究の蓄積、軽い筋肉、柔軟な接触 | コンプレッサ・弁、空気の圧縮性、ヒステリシス、収縮中の力低下 | **単関節・筋骨格型アームの第一比較候補** |
| 液圧McKibben型 | 同様の拘束構造を液体で駆動 | 大きな力、空気より小さい流体圧縮性 | ポンプ、漏洩、材料適合、端末耐久、配管損失。管自体の柔らかさは残る | 高トルクの水利栓用途を検討 |
| HASEL | 絶縁液入りの高分子袋を電気的に変形 | 柔らかい電動駆動、外部流体配管を減らせる | 高電圧駆動、封止、絶縁、束化、力と変位の整合 | 指・手首・研究用肩関節の候補 |
| 誘電エラストマー（DEA） | 柔らかい電極で挟んだ薄膜を電界で変形 | 軽量、積層可能、電気で直接駆動 | 薄膜欠陥、絶縁破壊、電極疲労、予張力・積層品質 | 材料・アクチュエータ研究向け |
| 撚糸・コイル高分子筋（TCP） | ナイロン等の撚った繊維を加熱して収縮 | 素材入手性、単繊維の実験を始めやすい | 冷却時間、保持中の消費電力、表面温度、熱履歴 | 小型・低速の機構実験から |
| 液晶エラストマー（LCE） | 配向した高分子の状態変化を利用 | 材料に変形方向を設計できる | 合成、配向、加熱/光入力、冷却、スケールアップ | 材料研究が主目的なら候補 |
| 3Dプリント流体アクチュエータ | 柔らかい外殻と内部流路を一体成形 | 指の曲げや複雑な形状を作りやすい | 流路・肉厚品質、材料、繰返し寿命、外部圧力源 | 収穫用指・柔軟ハンドに適した研究候補 |
| 電気流体繊維 | EHD繊維ポンプ＋細いMcKibben型の閉回路 | 圧力源を繊維側へ統合できる | 電気・流体・繊維の複合設計、駆動電源、流体状態、再現性 | **2026年の注目研究候補**。市販サーボ同等の完成度とは扱わない |

根拠資料：空圧は[Festo DMSPの2026年技術資料](https://www.festo.com/media/catalog/202851_documentation.pdf)、液圧は[東工大・ブリヂストンの研究](https://www.titech.ac.jp/news/2017/037300)、HASELは[メーカーの技術説明](https://www.artimusrobotics.com/)、DEAは[多層化を扱う原著論文](https://pubmed.ncbi.nlm.nih.gov/35857538/)、TCPは[釣糸・縫糸による人工筋肉の原著論文](https://pubmed.ncbi.nlm.nih.gov/24558156/)、LCEは[形状保持・自己検知を扱う原著論文](https://pubmed.ncbi.nlm.nih.gov/35584225/)。新しい流体方式の実証は次節に記載する。

## 5. アームの構成案と必要な力

### 5.1 初号機の案

固定架台に剛体の骨格・軸受を置き、6軸のうち各関節を拮抗する2本の筋肉で駆動する。手は3駆動程度の柔軟指とし、用途に応じて工具に交換する。これは試算用の構成案であり、人体の全筋肉・全自由度を再現するものではない。

- 腕：6関節×2筋＝12筋。筋の直線運動を腱・プーリ等で回転へ変換する。
- 指：3筋＋復帰ばね等を仮定。腕と合わせて15制御系統。
- 角度・張力・圧力を計測し、姿勢と接触力を制御する。
- 圧力喪失・腱切れ・通信断に備え、支持・保持機構と状態遷移を設ける。
- 圧力源は最初は架台側に置く。可搬化の評価時はその重量・電力も含める。

拮抗筋の張力差がトルクを生む。両筋の張力を同時に増やすと剛性を変えられるが、軸受荷重・消費エネルギーも増える。多軸関節や可変モーメントアームでは、筋数と制御系統がさらに増える。

### 5.2 20 N·m関節の計算例

仮定：一定の有効半径30 mm、関節角90度、必要な正味トルク20 N·m。摩擦、予張力、加速度、姿勢による半径変化はこの簡略計算に入れない。

```text
必要な張力差 = トルク / 有効半径
               = 20 / 0.03 ≈ 667 N

必要な腱の移動量 = 有効半径 × 回転角
                 = 0.03 × (π/2) ≈ 47 mm

使用できる収縮率を20%と仮置きすると
必要な筋の初期長さ ≈ 47 / 0.20 ≈ 236 mm
```

667 Nは片側筋の十分な定格を意味しない。反対側の予張力、摩擦、負荷変動を追加し、**47 mm収縮した位置でも必要な力が出るか**を曲線で確認する。筋の長さには端末・取り回しの余裕も必要。小さな関節にすべて収納できるとは限らない。

### 5.3 形状別の農業作業への適用

| 用途・形状 | 人工筋肉で担う部分 | 残る機構・課題 |
|---|---|---|
| トマト等の収穫 | 柔軟指、接近時の接触、把持力調整 | 果柄切断、衛生・洗浄、傷・汚れへの耐久 |
| 丸ハンドル | 把持、接触追従、回転力の伝達 | 多回転は握り替え、ラチェット、回転工具等が必要 |
| T形・十字形 | 形状に合わせた把持、レバー操作 | 干渉、滑り、反力、握り替え |
| 角軸・専用キー | 工具の位置合わせ、挿入、保持 | 適合ソケットと回転機構、抜け防止 |
| レバー・ロック付きレバー | 押引き、ロック解除、力制限 | 解除と回転の順序、終端衝突の防止 |
| 上昇軸・上下動ゲート | 位置追従、引上げ/押下げ支援 | 長ストローク、荷重支持、台座反力、必要なら別の直動機構 |

柔軟なアーム全体を大きくたわませる構成より、水利栓用途では剛体骨格や反力支持を残す設計が有力。全形状を扱うには、交換工具と握り替え動作が引き続き必要になる。

## 7. ROS 2による制御

関節の目標角度・トルクと、人工筋肉の圧力・電圧・温度は直接同じ量ではない。筋肉の長さ、負荷、履歴を含むモデルを同定する。

| 制御層 | 実装内容 |
|---|---|
| ハードウェア保護 | 圧力・電気・温度の制限、漏れ・断線検知、保持・停止機構 |
| 筋肉の制御 | 圧力/張力/電圧等のフィードバック。必要な周期は弁・筋・通信の実測から決める |
| 関節の制御 | 目標トルクを拮抗筋へ分配。張力下限、圧力上限、可動域を扱う |
| 腕の制御 | 重力補償、軌道、インピーダンス、工具の接触状態 |
| ROS 2接続 | ros2_control用のハードウェア実装、状態公開、計画系との接続、記録 |

物理構造が柔らかくても、位置・張力の閉ループが不要になるわけではない。ETHのHASEL肩の自己検知は有用な研究例だが、自作筋で同等の推定精度が得られるかは検証が必要。[ETH研究資料](https://srl.ethz.ch/platforms/ems/self-sensing-hasel-shoulder.html)

URDFではまず骨格関節を表し、筋長・張力・関節への変換は制御側で管理する。柔軟体の変形まで重要な場合は、剛体モデルとは別のモデル・検証を追加する。ROS 2統合の共通事項は[内製調査の第9節](robot_arm_full_stack_research_and_requirements.md#9-ros-2制御ソフトウェアとの接続)を参照。

## 9. 資格・設備条件の変更点

人工筋肉方式に共通する一括の製造免許ではなく、採用する作業と設備で要件を決める。共通の根拠・資格一覧は[内製調査の第10〜11節](robot_arm_full_stack_research_and_requirements.md#10-日本で必要になる資格教育選任)を参照。

| 作業 | 確認する項目 |
|---|---|
| 空圧・液圧装置の製作 | 圧力容器・蓄圧器・ガス設備等の区分、保守・検査要件。空圧装置を持つだけで一律に高圧ガス資格が必要とはしない |
| HASEL/DEA/EHDの電気設備 | 電圧・作業内容に応じた電気取扱教育、工事資格等。低消費電力と接触安全を同一視しない |
| 高分子合成・接着・溶剤 | SDS、化学物質管理、対象物質に応じた主任者・設備要件 |
| 繊維・CNT・粉体加工 | 使用形態・ばく露に応じた評価、集じん・保護具・管理。材料名だけで扱いを一律に決めない |
| 加工・ロボット試験 | 機械加工の対象作業教育、ロボット教示・検査等の条件 |

柔らかい筋肉でも張力・圧力・蓄積エネルギーは存在する。停止時に圧力を一律開放すると腕が落下する構成もあり、負荷を支持した状態での停止手順を設計する。

## 10. 研究を進める順序

1. 同じ寸法・負荷で、市販基準筋と自作編組筋の力―変位―圧力、履歴、漏れを測る。
2. 単関節を組み、角度・張力を計測して制御する。停止、圧力喪失、センサ故障時を試験する。
3. 骨格2〜3軸と柔軟指で、把持・工具挿入・レバー操作を実証する。
4. 6軸化し、全形状区分の水利栓工具と握り替えを検討する。未測定の固着トルクは能力保証に含めない。
5. 同一の評価治具でHASEL、液圧筋、EHD繊維等を比較し、用途ごとに置換する。
6. 材料合成・半導体・製造装置の内製は別の到達判定で進め、人工筋肉の動作実証と混同しない。

評価指標は、連続して出せる力、使用ストローク、応答、保持時消費、圧力源/電源込みの重量・効率、繰返し寿命、温湿度・水・泥への耐性、修理時間とする。最大値一つだけで採否を決めない。
