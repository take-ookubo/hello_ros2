## 2. 想定条件と価格の読み方

- リーチ：60〜80cm。低速の収穫試験を想定。
- 先端総荷重：ハンド、カッター、果実、センサ、配線を含め約1kgを設計目標とする。
- 設置：固定架台、商用AC電源。台車・昇降軸・バッテリーは対象外。
- 現在のリポジトリ：ROS 2 Humble / Ubuntu 22.04系Docker、Tesseract。実機接続にはLinuxホストを用意する想定。
- **掲載価格**：確認できたメーカー／販売店の表示額。メーカー希望価格の場合はその旨を記載。
- **予算枠**：本資料独自の設計段階の見込み。販売価格や正式見積を意味しない。
- **未確認／要見積**：価格、在庫、仕様の一部を公開情報で確定できなかったもの。欠落を安価な推定値で補わない。
- 外貨の予算換算は便宜的に **USD=150円、EUR=165円、CHF=175円**。現在の為替レートを表すものではない。
- 海外価格の円換算には、日本向け送料、輸入時の税・手数料を含めない。国内価格は税込表示を優先。
- 在庫表示はページ・取得時点によって食い違うことがある。表中の在庫は確約納期ではない。注文、問い合わせ送信、CADアップロードは実施していない。

### 3.3 トルク・保持機構を決める条件

先端1kg、水平距離0.7mの静的トルクだけなら `1 × 9.81 × 0.7 = 6.87 N·m`。しかし、肩にはリンク、肘モータ、手首モータの重量もかかる。例えば、下流機構3kgの重心が肩から0.35mなら、それだけで約10.3N·m追加される。

- 各軸について `Σ(m × g × 水平距離)`、加減速、想定デューティ、放熱条件を計算する。
- 定格トルクでも静止保持時の熱条件が同じとは限らない。最大張り出し姿勢での保持試験が必要。
- カタログ上の繰返し精度は、リンクたわみやバックラッシュを含む完成アームの手先精度ではない。
- 腕を支持する出力軸受のモーメント許容値を確認する。モータのトルクだけで選ばない。
- 回転数とトルクの関係も確かめる。XM540-W270は12Vで無負荷30rpm（3.14rad/s）で、そこではトルクが出ない。シミュレーション（READMEの「モータの回転数とトルク、電流の制限」）では、手首を3.0rad/sで返すと出せるトルク0.48N·mに対し0.67N·mが必要だった。そのため手首の速度上限を2.0rad/s（XM430は3.0rad/s）に下げた。手首を速くしたい場合は、14.8V駆動（無負荷37rpm）か減速比の小さい型番を比べる。
- RMDの上記候補はブレーキなし。肩・肘の重力補償ばね、外付け保持ブレーキ、停止時に支える機構を機械設計に含める。型番は必要保持トルクと取付寸法が決まるまで未選定。

## 13. 農業用水利栓の開閉：推奨構成

追記調査日：2026-11-06。ユーザー指定により、特定形状に限定せず比較する。

**全形状を扱う自作機には、「位置合わせ用アーム＋交換工具＋独立した回転／直動駆動＋反力支持」を推奨する。** アームの手首そのものを何十回も回して開栓する構成ではなく、工具の出力軸を回す。丸ハンドルをつかむ工具、角軸に差すソケット、レバー用フォーク、ゲート用フックを交換する設計とする。

ただし「全形状を対象に調査する」ことと「任意の寸法・トルクの栓を1台で操作できる」ことは異なる。実機の適用範囲は、形状ごとに寸法、必要トルク／推力、回転数、工具の侵入空間を登録して定義する。埋設ボックスの蓋開け、大型水門、固着弁の復旧は追加の機構・負荷評価が必要。

| 構成 | 適する用途 | 本資料での判断 |
|---|---|---|
| 栓ごとの専用電動化 | 同じ場所の栓を継続的に自動開閉 | 費用と保守の比較基準。既製品が適合するなら有力 |
| 固定治具＋回転工具／直動工具 | 単一形状・単一場所の実験 | 最初の検証に推奨。腕を買う前に必要トルクを測れる |
| 6軸アーム＋交換工具＋反力支持 | 異なる形状・向き・高さを同じ機体で操作 | 今回の全形状対応の本命。参考予算約292万〜316万円、走行系別 |
| 移動台車＋上記アーム | 圃場内の複数地点を巡回 | 台車、自己位置推定、停車固定、電池、泥道走行を別設計。今回のBOMには含めない |

収穫用との主な差は、柔らかい指・カッターを、**確実にかみ合う工具、トルク計測、繰返し回転、反力固定、屋外防護**へ置き換える点である。第11節の1kg級先端荷重や小型手首を、そのまま流用できるとは判断しない。

### 14.1 公開仕様から分かる回転数の違い

[旭有機材「自由型アングルバルブ」取扱説明書 H-V018-J-11](https://doc-admin.asahi-yukizai.co.jp/doc/h-v018-j)では、全閉から全開まで50mmが16回転、80mmが24回転。24回転を工具出力5rpmで回すと、回転時間だけで4.8分かかる。したがって、短い回転を繰り返す手首動作と、専用回転工具では処理時間が大きく変わる。

同説明書には手での操作、終端で過大な力を加えないことなどの条件がある。これを根拠に無条件で動力化できるとはしない。メーカー指定の操作方法から外れる場合は、適合する電動化製品、許容操作荷重、取付方法の確認を調達課題として残す。

## 15. 駆動力・反力・センシングの選定

### 15.1 トルクは実測で決める

収穫機の把持力から水利栓のトルクを推定しない。各型番について、使用水圧下で開き始め、途中、閉じ始め、着座時のトルクと角度を記録する。固着した個体を正常個体と同じトルクで動かせると仮定しない。

[旭有機材の農業用水技術資料](https://www.asahi-yukizai.co.jp/datas/news/10000/7p8OnpJWwZ.pdf)には、特定のAVゲートバルブ・キャップ式の締切トルクとして、呼び径50mmで15N·m、75(80)mmで25N·m、100mmで30N·mという例がある。これは**その弁種・資料の値**であり、アルファルファーバルブ等の始動トルクや破損限界を表さない。検索で確認できた旧技術資料の数値のため、採用品の現行仕様を優先する。

本追記の費用モデルは、**工具出力の評価範囲を最大30N·m、直動工具を最大500N程度と仮置きした試作**である。全ての栓にこの力を掛ける設定ではなく、弁ごとの許容値より低い制限を設定する。範囲外の大型弁・固着弁・大型ゲートは別サイズの工具と再見積の対象。

### 15.2 反力を受ける構造

- トルク30N·mを半径0.1mで受けると接線力は `30 / 0.1 = 300N`。収穫用の軽い手首や柔らかい指とは負荷の性質が異なる。
- 全てを腕で受ける場合、先端の力・モーメントによる関節負荷を `τ = Jᵀw` で評価し、重力・加減速分を加える。台座の滑りや転倒も計算する。
- 推奨は、工具モータの筐体側を支持治具に固定し、回転軸から栓へトルクを伝える構成。反力は**工具筐体→反力アーム→支持架台／承認された固定箇所**へ流す。
- 樹脂製バルブ本体や埋設管へ、確認なしにクランプして反力を負担させない。必要なら独立した支柱・架台・ドッキング部を設ける。
- 反力固定後も、アームに荷重が全く掛からないわけではない。偏心、工具重量、固定部のたわみ、挿入力を評価する。
- 多回転軸は工具内部で回し、腕の配線を巻き付けない。昇降スピンドルには追従ストロークを設ける。

低速回転に必要な機械出力の例は `P = T × 2πn/60`。30N·m・5rpmなら約15.7Wだが、これだけで20Wモータを選べるわけではない。減速機効率、始動、低速温度、許容出力トルク、デューティを加えて選定する。

## 17. ROS 2での制御構成

アーム位置決めはMoveIt 2＋ros2_controlを継続し、回転工具・直動工具は独立したハードウェアインターフェースまたは専用ROS Actionサーバとして実装する。

| 処理 | 実装案 | 判定に使用するデータ |
|---|---|---|
| 対象識別 | 栓IDごとの型番・工具・操作条件を読み出す | 画像、マーカー、登録位置 |
| 接近・芯合わせ | MoveItで接近し、低速の視覚／力フィードバックで位置修正 | カメラ、軸方向接触力 |
| 工具装着 | 専用工具を挿入／クランプし、装着を検出 | 挿入量、ラッチ、近接／接点センサ |
| 反力固定 | 支持部を固定し、固定状態を確認 | 固定位置、荷重、ロック検出 |
| 開閉 | 工具側で速度・トルク上限・回転数／ストロークを管理 | 出力軸角度、トルク、上下端 |
| 結果確認 | 開度と水の状態を別々に判定 | 回転数、流量、水位、時間 |
| 離脱 | 荷重を抜き、工具と反力支持を外す | 残留荷重、工具位置 |

操作Actionには、`valve_id`、`tool_id`、開閉／目標位置、速度上限、トルク／推力上限、最大回転数／ストローク、タイムアウトを持たせる。実行結果は成功だけでなく、装着失敗、反力固定失敗、過負荷、空転、回転数超過、状態不明を区別する。これは提案仕様で、既存の標準ROSメッセージではない。

Oriental Motorの[Modbus製品ページ](https://www.orientalmotor.com/network-products/modbus-rtu-network-products.html)にはROS 2向けソフトウェアへの案内がある。ただし、BLH/AZの注文型番、レジスタ、ROSディストリビューションの組み合わせまで動作確認済みとはしない。UTMⅢのRS-485とBLHのModbusも、同じ物理層だから同じプロトコルとは限らない。

トルク・推力制限と通信断処理は工具側／ドライバ側にも持たせる。停電・中断後に無条件で再回転せず、栓位置が復元できなければ状態不明として再確認する。水位だけから全閉位置を決めない。操作速度は対象配管に合わせ、急閉止の影響を評価して決める。

### 18.2 栓ごとの既製電動化との比較

ロボットアームが複数地点を回る価値を評価するため、専用機も比較基準として掲載する。

| 製品 | 確認できた価格／条件 | 対応と制約 |
|---|---|---|
| [farmo 給水バルブ](https://farmo.info/paddy_valve/) | 99,000円税込、調査時注文可能表示 | ハンドルを外し軸を駆動する後付け候補。適合栓・固定支柱・通信環境を確認。全形状対応ではない |
| [farmo 水位センサー](https://farmo.info/paddy_sensor/) | 27,500円税込 | 給水バルブと組み合わせる場合、掲載額合計126,500円。必要構成と適合は販売元確認 |

いずれも公開ページだけでは、ROS 2から任意に指令を送れるAPIを確認できなかった。ROS連携を含めた製品として断定しない。直接電動化が許されるなら、全形状アームよりも有利になる可能性がある。一方、既存設備に機器を常設できない、複数の作業も兼ねる、といった条件ではアーム方式を評価する意味がある。

単純な「アーム価格÷バルブ単価」だけでは採算は決まらない。訪問地点数、移動時間、16〜24回転等の操作時間、同時給水の要否、保守、通信、設置工事を加えて比較する。

## 19. 全形状を対象とする検証・購入の順序

1. **全形状の実物台帳を作る。** 型番、呼び径、ハンドル／軸形状、寸法、高さ、回転方向、回転数、上下移動、ロックの有無、周囲の空間、水圧を記録する。
2. **代表個体のトルク・推力を測る。** 開き始め、途中、閉端、濡れ・泥・経年差を測定し、メーカー条件と照合する。全形状共通の30N·m設定にはしない。
3. **交換工具を固定治具で試す。** 丸輪・T形／角軸・レバー・上下ゲートの各系統を評価する。誤装着、脱落、空転、過負荷停止を確認する。
4. **反力固定と保持を成立させる。** 独立架台または適合を確認した固定点を用意する。上方向に引くゲートでは押下げと保持まで確認する。
5. **完成工具の重量・重心でアームを選ぶ。** 収穫用1kg想定を引き継がず、工具、チェンジャー、配線、支持機構を含めて各関節と台座を再計算する。
6. **ROS 2で形状ごとの手順を実行する。** 工具IDと栓IDが一致しなければ開始しない。開閉結果が不明なら完了にせず、履歴を保存する。
7. **最後に巡回機能を追加する。** 走行台車の停車誤差、地面沈下、傾斜、ドッキング、電池を評価する。位置合わせだけでなく反力支持の再現性を確認する。

本追記により全形状区分を調査対象にしたが、採用型番・力の上限を確定するには現地の寸法と負荷が必要である。未確定事項は調達条件として残し、価格が公開されていない機器を購入可能額として断定していない。
