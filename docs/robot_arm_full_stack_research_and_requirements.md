# 半導体・CMOS・製造装置から自作するロボットアーム：研究分野・設備・資格

調査日：2026-11-07。日本国内で研究・製造する場合を想定。

対象は、腕・手・指に加え、モータ、減速機、センサ、電子部品、半導体、CMOS回路、CMOSイメージセンサ、半導体洗浄装置を含む製造装置までの内製。完成部品を購入して組み立てる場合は、別資料の[購入候補比較](harvesting_robot_hardware_comparison.md)を参照。

本資料は研究開発計画のための技術分解である。公開一次資料で確認した製造技術・制度と、それを組み合わせた設計上の提案を区別する。設備仕様・費用・適用資格を確定するには、製造する物、工程、薬品、設備規模、所在地を決める必要がある。薬液の配合・処理条件・危険物を扱う装置の製作手順は対象にしない。

## 1. 結論と「全て自作」の境界

**必要なのは、ロボティクス、精密機械、電磁気・モータ、電子回路、半導体デバイス・製造、化学装置、材料、計測、制御・AI、設備保安を横断する研究開発体制である。** 半導体洗浄装置とCMOSまで自作する場合、アームの開発と並行して、小規模な半導体製造・装置開発拠点を構築することになる。

| 内製の段階 | 自分で行う範囲 | 外部に残るもの | 今回の扱い |
|---|---|---|---|
| 0：組立 | 購入した関節、カメラ、計算機の統合 | 部品の設計・製造 | 前回資料の中心 |
| 1：部品設計 | モータ・基板・ASICなどの設計 | ウェハ加工、精密加工など | 比較対象。半導体の製造自作とは区別 |
| 2：部品製造 | 巻線、歯車加工、半導体前後工程、センサ製作 | 工作機械、露光機、洗浄機、材料 | 今回の必須範囲 |
| 3：製造装置 | 洗浄機、成膜・加工・検査装置、搬送系も設計・製作 | 装置製作用の母機、基準器、原材料など | 追加依頼を含む今回の中心 |
| 4：原材料・母機 | ウェハ、磁石、金属、樹脂、薬品、製造装置を作る工作機械まで | 鉱物、エネルギー、初期の基準・道具など | 必要分野を明示。独立した産業群に相当 |

「全て」を採掘・精錬・発電・測定標準まで遡ると、製造装置を作る製造装置が必要になり、単一アームのBOMでは範囲を閉じられない。そこで本資料では**最終的な内製対象は広く保ち、開発開始時に借りる設備・計算機・基準器は別管理する**。初期の外部設備利用を、完成時の完全内製達成とは数えない。

CPUを自作しただけではGPU・メモリ・電源IC・イメージセンサまで自作したことにはならない。同様に、洗浄槽を製作しただけでは、半導体品質の洗浄工程が成立したことにはならない。

## 2. 「最先端」を性能要件に置き換える

最先端には、軽量で力制御が得意な腕、重負荷で高精度な腕、多指の器用な手など異なる方向がある。以下は仕様策定の提案であり、達成済み性能ではない。

| 評価軸 | 決める仕様・測る値 | 農業用途での意味 |
|---|---|---|
| 機械性能 | リーチ、姿勢別可搬、連続トルク、ピーク継続時間、剛性、質量 | 水利栓の固着を解く負荷と、水平に伸ばした腕の保持負荷を分ける |
| 運動精度 | 絶対位置精度、繰返し精度、軌跡誤差、熱ドリフト | 工具を角軸に差し込む精度と、同じ場所に戻る精度は別 |
| 接触性能 | 力・トルク分解能、制御帯域、摩擦、バックドライブ性 | 果実を傷めない把持と、栓を壊さない回転制御 |
| 認識性能 | 深度誤差、外光耐性、遅延、遮蔽・汚れへの頑健性 | 逆光、泥、水滴、葉の遮蔽、錆びたハンドルへの対応 |
| 運用性能 | 消費電力、温度上昇、連続運転、修理性、防塵・防水 | 最大出力より、現場で動き続ける能力 |
| 安全性能 | 停止距離、故障時挙動、重力落下防止、再起動条件 | 人・配管・作物に対してどの危険をどう抑えるか |
| 自律性能 | 未知対象での成功率、失敗検知、復帰率、介入回数 | デモの成功と現場運用の成功を区別 |

産業用ロボットの性能試験を整理する参考は[ISO 9283:1998](https://www.iso.org/standard/22244.html)。異なる負荷・速度・環境で測った数字をそのまま比較しない。ロボットの用途と同様、半導体も「最小線幅」だけで評価せず、必要な耐圧、ノイズ、消費電力、信頼性で工程を選ぶ。

バッテリーは固定式アームには必須ではない。油圧・空圧を採用する場合は、ポンプ/圧縮機、弁、シリンダ、配管、作動流体、圧力容器の設計・製造も追加する。これは電動関節の置き換え・補助の分岐であり、すべての方式を一台に搭載するという意味ではない。

### 4.1 モータの「巻線自作」と「材料から自作」の違い

巻線だけを自作する段階でも、スロット・極数、巻線方式、占積率、絶縁、含浸、放熱、ロータ保持、動釣合いを設計する。材料からなら、銅の精錬・線引き・絶縁被覆、電磁鋼板の製鋼・圧延・絶縁処理、磁石の合金・粉末・成形・焼結・表面処理・着磁まで増える。

例えば焼結ネオジム磁石には合金・粉末・磁場中成形・焼結等の工程がある。これはモータ組立とは別の材料製造技術である。[磁石メーカーの製造説明](https://www.sagami-magnet.co.jp/products/products_nd)

試験では、トルク定数、抵抗・インダクタンス、逆起電力、効率マップ、温度上昇、コギング、絶縁、減磁、軸受寿命を調べる。必要関節トルクは、姿勢別の重力負荷＋加減速負荷＋接触負荷から求め、連続運転は熱限界で判断する。モータ制御の基礎となるFOCと関連設計例は[TIの技術資料](https://www.ti.com/technologies/motor-control.html)が参考になる。

### 4.2 減速機と力制御

遊星、サイクロイド、波動歯車、低減速比・ダイレクトドライブを比較する。波動歯車では薄肉部材の弾性変形が動作原理に含まれ、単に形を削るだけで精度・疲労寿命が得られるものではない。[メーカーによる原理説明](https://www.harmonicdrive.net/technology/harmonicdrive)

出力側エンコーダ、トルクセンサ、摩擦推定を合わせて評価する。モータ電流からの推定トルクは、減速機の摩擦や効率、温度変化を含めた先端接触力の直接測定とは異なる。

## 5. CMOS回路・半導体を製造するための技術と設備

### 5.1 CMOSは一種類の部品ではない

CMOSは相補型MOS回路・技術を指す。**ロジック用CMOSと、受光画素を持つCMOSイメージセンサ（CIS）の両方**を今回の対象にする。

| 半導体の種類 | アームでの役割 | 自作で増える専門領域 |
|---|---|---|
| CMOSロジック・CPU・制御ASIC | 計算、PWM、通信、監視 | 論理設計、標準セル、クロック、電源配線、検証・テスト |
| アナログ・混載IC | ADC、電流・ひずみ計測、基準電圧 | 素子整合、低雑音、精密アナログ、校正 |
| パワー半導体・駆動IC | モータ電流のスイッチング、電源変換 | 耐圧構造、熱、絶縁、過渡特性。ロジック工程と別設計 |
| メモリ | OS、画像、学習モデル、ログ | SRAMセル、保持・耐久性。DRAM/不揮発メモリはさらに専用工程 |
| CMOSイメージセンサ | カメラ、光学式触覚 | 画素、受光効率、暗電流、光学・読出し、画素ばらつき |
| MEMS | IMU、圧力、微細力覚 | 微細機械加工、解放工程、接合、応力、専用封止 |
| LED・レーザなど | 照明、測距、光学エンコーダ | 化合物半導体、エピタキシ、光学実装。Si CMOSだけでは完結しない |

アームに必要な耐圧・精度・消費電力を満たす成熟プロセスの研究と、最先端ロジックの微細化研究を分ける。成熟工程で作った関節制御ICでも、アーム全体として高度な性能は狙える。一方、現行の高性能GPUや大容量メモリを自作するなら、別規模の工程・設計・歩留まり開発が必要になる。

### 5.2 工程・設備・計測の対応

以下は工程群の一覧であり、特定CMOSプロセスの実行順序・レシピではない。設計した素子構造によって採用工程が変わる。

| 工程群 | 必要な装置 | 装置自作で必要な技術 | 主な測定 |
|---|---|---|---|
| 基板製造 | 結晶成長、切断、研削・研磨、洗浄 | 高純度材料、結晶欠陥制御、精密加工 | 抵抗率、結晶欠陥、平坦度、汚染 |
| 洗浄・表面準備 | 湿式洗浄、リンス、乾燥、搬送 | 化学・流体・材料・発塵管理。第6節で詳細化 | 粒子、金属、有機物、表面状態 |
| リソグラフィ | 塗布、ベーク、露光/描画、現像 | 光学、精密ステージ、位置合わせ、温調 | 解像、寸法、重ね合わせ、欠陥 |
| 膜形成 | 酸化炉、CVD/ALD/PVD等 | 真空、ガス、熱、プラズマ、膜応力 | 膜厚、均一性、組成、電気特性 |
| 素子特性形成 | 拡散/注入、アニール等 | ドーピング、熱履歴、欠陥回復 | 濃度・深さ、シート抵抗、接合特性 |
| パターン加工 | 湿式/乾式エッチング等 | 選択性、異方性、プラズマ制御 | 加工形状、残渣、表面損傷 |
| 配線・平坦化 | 金属成膜、めっき、CMP等 | 密着、バリア、研磨、低欠陥接続 | 抵抗、段差、平坦度、配線信頼性 |
| 後工程 | ダイシング、ダイ接合、ワイヤ/フリップチップ接合、封止 | 精密位置決め、接合材料、熱応力 | 接続、気密・湿度、熱抵抗 |
| 電気試験 | プローバ、SMU、LCR、テスタ、温調ステージ | 低雑音計測、治具、テストパターン | 素子・回路機能、ばらつき、寿命 |

半導体は成膜・露光・加工・計測を繰り返して形成する。[ASMLの工程解説](https://www.asml.com/en/technology/all-about-microchips/how-microchips-are-made)

研究設備の具体例として、NISTは露光、成膜、ドライエッチング、炉、湿式処理、SEM、CMP、ダイシング、プローバ等を公開している。この一覧は**研究用微細加工設備の例**であり、それをそろえれば最新CPUを製造できるという保証ではない。[NIST BMF設備一覧](https://www.nist.gov/pml/boulder-microfabrication-facility-tools-capabilities-and-infrastructure)

### 5.3 設計環境も内製範囲に含める場合

必要なのはTCAD、SPICEモデル、PDK、DRC/LVS、寄生抽出、論理合成、配置配線、タイミング解析、テスト設計である。自作プロセスでは、外部ファウンドリのPDKをそのまま使えない。テスト素子を製造・測定し、モデルと設計ルールを作り、回路の実測と照合する必要がある。

CPUから自作するなら、命令セットの実装だけでなく、ブート、デバッグ、メモリ制御、コンパイラ対応、RTOS/Linuxへの移植も必要。製造装置を制御する計算機の開発と、最終アームの計算機の開発は、初期設備を使って段階的に進める。

## 6. 半導体洗浄装置そのものを自作する

### 6.1 方式を分ける

| 方式 | 自作する主要部分 | 研究課題・選択上の違い |
|---|---|---|
| バッチ式湿式洗浄 | 槽、ラック、搬送、液管理、リンス、排気 | 複数枚処理、槽内均一性、持ち込み・交差汚染 |
| 枚葉式洗浄 | スピン部、保持部、ノズル、カップ、供給・回収 | 表裏・端部の処理、回転振動、液膜、飛散・再付着 |
| 物理力を使う洗浄 | ブラシ、流体噴射、音響系など選択した方式 | 粒子除去と微細構造の損傷の両立 |
| 乾燥 | 選択方式に応じた回転・気流・雰囲気管理 | 水跡、残渣、静電気、微細パターン倒壊 |

TELは枚葉式、バッチ式、物理洗浄等を展開し、洗浄だけでなく乾燥も工程品質に関わると説明している。[TELの工程・製品解説](https://www.tel.com/product/)、[CELLESTA](https://www.tel.co.jp/product/cellesta.html)。これらは必要機能を知るための参照であり、公開仕様だけで市販装置と同等の性能を再現できるわけではない。

### 6.2 洗浄機の構成と必要なハードウェア

| サブシステム | 必要な部品・設備 | 自作時の検証項目 |
|---|---|---|
| ウェハ保持・搬送 | チャック、エッジ保持、キャリア、搬送軸、エンドエフェクタ | 接触傷、破損、発塵、位置ずれ、裏面汚染 |
| 接液部 | 槽、配管、継手、バルブ、ノズル、シール | 薬品・温度適合、溶出、吸着、透過、粒子発生 |
| 供給・循環 | ポンプ、フィルタ、流量・圧力計、温調、計量系 | 脈動、気泡、デッドスペース、流量再現性 |
| 超純水 | 原水前処理、精製、ポリッシング、循環・末端ろ過 | 比抵抗だけでなくTOC、粒子、金属、微生物等 |
| 清浄環境 | 局所清浄化、ろ過空気、差圧、清浄搬送空間 | 空中粒子、材料由来汚染、保守後の清浄復帰 |
| 排気・封じ込め | 密閉/囲い、局所排気、処理設備、漏洩検知 | 排気喪失、漏れ、異常時の供給停止 |
| 廃液 | 系統分離、回収容器、液位監視、二次受け、処理・保管 | 不適合な廃液の混合防止、誤接続、追跡可能性 |
| 制御 | I/O、制御器、モータドライバ、監視、履歴保存 | 通信断・停電・センサ故障時の状態遷移 |
| 保護系 | 独立した停止系、扉監視、過温・空焚き・漏洩・排気監視 | 一つの制御故障が供給継続につながらない設計 |

接液材にはPFA/PTFE、石英などが候補になるが、材質名だけで適合性は決まらない。薬品、温度、純度、機械荷重ごとに選定・評価する。超純水・薬液供給系の高純度樹脂材料・部品については[SEMI F57](https://store-us.semi.org/products/f05700-semi-f57-specification-for-polymer-materials-and-components-used-in-ultrapure-water-and-liquid-chemical-distribution-systems)が参照になる。樹脂やフィルタまで自作する場合は、高分子合成、精製、成形、膜製造、溶出分析も追加される。

### 6.3 洗浄性能を証明するための計測

「見た目がきれい」「水の電気抵抗が高い」だけではCMOS工程への適合を判定できない。以下は試験計画の提案であり、合格値は対象工程から決める。

- 洗浄前後の粒子数・粒径分布、装置が新たに付けた粒子、端部・裏面の汚染を測る。
- 金属・イオン・有機残渣について、TXRF、ICP-MS、イオンクロマトグラフィ、TOC等から目的に合う測定方法を選ぶ。分析装置も自作するなら別の装置研究になる。
- 膜厚、表面粗さ、濡れ性、酸化状態、微細パターン損傷を確認する。
- 最終的にはテストMOS構造の漏れ電流、絶縁膜品質、CMOS回路の歩留まり、CISの暗電流・欠陥画素に結び付けて評価する。
- ウェハ間・日間・保守前後の再現性、薬品・水・エネルギー消費、故障時の封じ込めも記録する。

自作の第一段階は、薬品プロセスに入る前に清浄水で搬送・液供給・漏洩検知・停止系・粒子増加を検証する構成が適する。これは段階的な検証案であり、実工程用の安全設計・施設要件を置き換えるものではない。

## 7. CMOSイメージセンサとカメラを自作する

| 階層 | 必要な技術・ハードウェア | 評価する性能 |
|---|---|---|
| 画素 | フォトダイオード、画素トランジスタ、分離構造 | 量子効率、暗電流、飽和電荷、欠陥画素 |
| 読出し | 行列選択、増幅、ノイズ低減、ADC、タイミング | 読出し雑音、固定パターン、フレームレート |
| シャッタ | ローリング/グローバル方式に応じた回路・画素 | 動体歪み、残像、感度とのトレードオフ |
| 光学 | カラーフィルタ、マイクロレンズ、撮影レンズ、照明 | 色再現、集光、歪み、解像、迷光 |
| 実装 | パッケージ、窓材、封止、放熱、基板 | ゴミ、結露、平面度、温度依存 |
| カメラ化 | 電源、通信PHY、ISP、時刻同期、ドライバ | 画像欠落、遅延、同期ずれ、校正安定性 |
| 深度化 | 複眼校正、または選択した能動測距方式 | 距離精度、外光・反射・遮蔽への耐性 |

最初の自作CISは、小規模なモノクロ・表面照射の画素アレイから段階的に評価する案が考えられる。高性能CISに進む場合、裏面照射では薄化、接合、裏面処理、欠陥制御が追加される。積層型では画素層とロジック層の接合・接続を開発する。Sonyの[裏面照射の説明](https://www.sony-semicon.com/en/technology/is/back-illuminated.html)と[積層・2層トランジスタ画素の説明](https://www.sony-semicon.com/en/news/2021/2021121601.html)が、この追加工程の理解に役立つ。

必要な測定設備は、暗箱、校正光源、積分球、波長選択光源、温調、画像取得系、光学評価治具。カメラ性能の評価方法には[EMVA 1288](https://www.emva.org/wp-content/uploads/FSF-VS-Brochure-2021-A4-vf-lowres.pdf)を参照する。測定系の光量・温度が校正できなければ、センサ改良の効果を判断できない。

**CMOSイメージセンサを作ることと、屋外で安定する深度カメラを完成させることは別の開発項目**である。収穫・水利栓用途では、画素数だけでなく外光、動作中の歪み、汚れ、距離測定の失敗を評価する。

設備規模は製造方式に依存する。全室をクリーンルームにする方式だけでなく、局所清浄化もある。ただし、機械加工・磁性粉末・樹脂成形と、半導体の清浄工程は、粉塵・金属汚染を持ち込まないよう区画・搬送・保守を設計する必要がある。

最先端の露光・計測装置まで自作するなら、光学部品、レーザ、超精密加工、位置基準、制御器などが再び研究対象になる。市販CPU相当の最先端プロセスと、研究用CMOSの実証ラインを同じ設備計画にしない。

## 9. ROS 2・制御ソフトウェアとの接続

| 層 | 主な役割 | 自作側で必要な実装 |

ROS 2を利用しても自動的に時間保証や機械安全が得られるわけではない。周期、最大遅延、ジッタ、通信断時の挙動を設計する。特に電流制御は関節内で閉じ、ホストとの通信を失っても定めた状態へ移る構成を検討する。[ROS 2リアルタイム設計資料](https://design.ros2.org/articles/realtime_background.html)、[ros2_controlのController Manager資料](https://control.ros.org/kilted/doc/ros2_control/controller_manager/doc/userdoc.html)

自作チップがROS 2を直接実行する必要はない。小さな関節ASICと上位計算機を分けられる。ただし上位計算機も最終内製するなら、メモリ・周辺回路・OSまで工程表に残す。

### 10.1 取得が有益だが、一律の開発必須条件ではないもの

## 13. 開発の依存関係と到達判定

以下は実行順序の提案。完全内製の目標を保ちながら、各段階の性能を確認して進める。必要人数・年数・費用は、寸法・性能・ウェハ径・工程・内製率が未定のため確定しない。

| 段階 | 完成させるもの | 次へ進むための証拠 |
|---|---|---|
| 1：仕様・測定基盤 | 代表作業、負荷・熱・精度要求、計測治具、内製台帳 | 校正された負荷・寸法・電気・温度の測定ができる |
| 2：単関節 | 自作モータ、ドライバ、機構、センサ、ブレーキ | 連続トルク、温度、力制御、異常停止を実測 |
| 3：腕・手 | 複数関節、工具、上位制御、ROS 2接続 | 代表姿勢・接触作業で性能と故障時挙動を確認 |
| 4：製造装置の基礎 | 洗浄機、搬送、清浄環境、ユーティリティ、計測 | 装置起因の汚染・損傷、再現性、保護機能を測定 |
| 5：素子・工程 | テスト構造、MOS素子、CMOSインバータ等 | 電気特性、ばらつき、膜・寸法・汚染との関係が説明できる |
| 6：小規模IC・CIS | センサ読出し/制御IC、小規模画素アレイ | 回路歩留まり、ノイズ、光応答、温度依存が仕様内 |
| 7：システム置換 | 自作IC・センサ・電源を関節・カメラに搭載 | 購入品ベースの基準機との同条件比較、長時間運転 |
| 8：高度化・内製拡大 | 高精度力制御、高性能CIS、演算系、材料・母機 | 研究目標ごとの改善と、未内製部品・工程の減少を確認 |

単関節・アームの研究と、半導体・装置の研究は並行可能。ただし自作洗浄装置の完成を待たないとアーム制御を試せない計画や、自作CPUがないと露光機を制御できない計画にすると、依存関係が循環する。初期設備を明示して借り、段階ごとに置き換える。

## 14. 最初に作るべき設計資料

1. **内製範囲台帳**：対象物、設計者、製造場所、材料供給元、外部設備、最終置換予定を記録する。小さな受動部品・フィルタ・軸受・ソフトウェアも残す。
